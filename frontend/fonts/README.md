# Material Symbols Rounded

Fuente de Google Material Symbols Rounded bajo licencia Apache 2.0.
Este subconjunto se sirve localmente para que los iconos funcionen sin Internet.
Para regenerarlo, pide por `icon_names` las ligaduras del frontend, en orden
alfabético, en la [API de Google Fonts](https://developers.google.com/fonts/docs/material_symbols).
